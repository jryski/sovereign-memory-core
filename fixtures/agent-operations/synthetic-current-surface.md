# Synthetic local corpus

This file is a test fixture. It is not a deployment document, and it does not
name a person, a project, or a private path. It teaches only signatures that
are on the recorded public surface.

- `session_boot(text)`
- `hot_touch(text, uuid, text, text)`
- `supersede_memory(uuid, text, text, text, text[], timestamp with time zone)`

Prose that is not a type-only signature stays out of the comparison, for
example `select session_boot('<viewer>')` and `remember(...)`.
